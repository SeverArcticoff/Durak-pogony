# Дурак 2×2 — Погоны (прототип 0.1)
Запуск: установить Node.js 18+; в папке проекта выполнить `npm start`. Открыть http://localhost:3000. Для четырёх телефонов в одной Wi-Fi сети открыть http://IP-компьютера:3000 (разрешить порт в брандмауэре). Для игры из разных городов разместить Node.js приложение на хостинге с HTTPS, командой запуска `npm start` и переменной PORT от хостинга. Внешние пакеты не нужны. Создать комнату, отправить ссылку троим игрокам; первый и третий — одна команда, второй и четвёртый — другая. 
Правила прототипа: 36 карт, подкидной, подкидывают только противнику; до шести атакующих карт и не больше исходной руки отбивающегося. Погоны разрешены после исчерпания колоды, когда противник объявил, что берёт неотбитую атаку, а у атакующей команды остались только карты текущего звания, по 0–3 на руку, в сумме не меньше двух (для финала одна Д♠). Погоны повышают общее звание комнаты: 6→7→8→9→10→В→Д→К→Т→Д♠; затем новый цикл. Обычная победа звание не меняет. Это рабочая интерпретация пользовательского правила, требующая проверки за игровым столом. Состояние комнат хранится в оперативной памяти, при перезапуске сервера теряется. Не является опубликованным сервисом; нет постоянного рейтинга, выхода с заменой игрока, звука или полноценной анимации.
